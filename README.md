# Daisy Disaster 

**Cute things. Questionable decisions.**

Daisy Disaster is a playful online shop built with React, Next.js, TypeScript and Tailwind CSS. The shop uses the Noroff Online Shop API to display products and allows users to browse, search, sort, add products to their cart and complete a demo checkout.

## Features

- Browse products fetched from the Noroff Online Shop API
- View individual product details, descriptions, tags and reviews
- Search products by title
- Sort products by price and rating
- View discounted prices and discount percentages
- Add products to a shopping cart
- Update product quantities and remove items from the cart
- Cart data persists using localStorage
- Complete a demo checkout process
- View an order confirmation page
- Contact form with input validation
- Responsive layout for desktop and mobile devices

## Getting started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone [YOUR REPOSITORY URL]
   ```

2. Navigate into the project folder:

   ```bash
   cd onlineshop
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## API

Product information is retrieved from the Noroff Online Shop API:

https://v2.api.noroff.dev/online-shop

## Notes

The checkout is a demonstration of an online shopping flow. It does not process real payments or create actual orders.

The contact form is a frontend demonstration and does not send emails.
